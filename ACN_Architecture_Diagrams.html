Authentication Flows
ArcGIS (Geospatial Data)
Private datasets: short-lived Bearer token (14-day expiry) stored as a server-side environment variable. Passed as a URL parameter on FeatureServer API requests. Public datasets require no token.
mAI Factory (AI Inference) — Posit Connect OAuth
Posit Connect auto-injects a per-session token. Application exchanges it for an Azure AD Bearer token via RFC 8693 token exchange. Bearer token sent to the WBG mAI Factory gateway. No API keys stored in application code.

Figure 2: Zambia GeoHub AI Assistant — End-to-End Process Flow
Data flow from user query through geospatial retrieval, AI inference, and display
1
User Query
User submits a natural language question via the web chat interface. Optional: attach a document (PDF/Word) or map image for additional context.
2
Intent Detection
Server-side processing classifies the query intent: Chatbot Q&A, Report Generation (.docx / PDF), or Dataset Summary.
3
Location & Topic Extraction
Geographic entity (district or province) and thematic keyword (e.g. schools, health, floods) are extracted from the query text to guide dataset selection and API filtering.
4
Dataset Catalog Search
The application scores ~80 curated Zambia GeoHub dataset entries against the query using keyword ranking. The highest-scoring relevant dataset is selected for retrieval.
5
Geospatial Data Retrieval — ArcGIS REST API
HTTPS request to the Zambia GeoHub FeatureServer. District or province filter applied. Returns up to 200 feature records as GeoJSON. Fallback: pre-loaded offline dataset if the live server is unavailable.
6
AI Prompt Construction
Structured prompt assembled from: user question + dataset metadata + up to 15 sampled records + pre-aggregated counts by area + system rules (no hallucination, cite sources, Zambia-only scope).
7
AI Inference — WBG mAI Factory
HTTPS POST to WBG mAI Factory (azapimdev.worldbank.org) with Azure AD Bearer token obtained via Posit Connect OAuth exchange. GPT-5 or Claude Sonnet generates the analysis. Response streamed in real time.
8
Display & Output
Results rendered in the browser: AI text analysis (streaming markdown) · Interactive map (district boundaries + data points) · Data table · Download (Word .docx / PDF generated in memory — no server storage).
