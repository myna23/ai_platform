CLASSIFICATION BASIS
------------------------------------------------------------------------------
  1. All datasets are published openly on the Zambia GeoHub
     (zmb-geowb.hub.arcgis.com) and are retrievable anonymously.
  2. Records contain facility names, categories and coordinates only.
     No personal data is present in any dataset in scope.
  3. The application sends no credential with any ArcGIS request, so a
     non-public layer would return an authorisation error rather than data.
  4. Private/token-gated access was removed from scope under OIS review —
     see story 186182 for the code-level removal evidence.
